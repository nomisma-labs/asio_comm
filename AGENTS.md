`asio_comm` is intended for C++ implementations of WebSocket, HTTP and other communication
protocols, initially for cryptocurrency exchanges. It currently contains the build scaffold
and a JSON configuration/logging example, without protocol implementations. `base`, `json_config`,
`spd_logger`, and `assembly` are repository dependencies. Boost is discovered through the shared
kit; Catch2 is available for tests.
